Stage 2: CSV to Parquet to MinIO

Project Overview

This project uses Apache Airflow to process a CSV file, validate it against a schema contract, transform the data into partitioned Parquet files, and store the output in MinIO.

Technology Stack

Python

Apache Airflow

Docker Compose

Pandas

Parquet

MinIO

YAML

Workflow

Read the input CSV from dags/extraction/sample.csv.

Validate the data against schema_contract.yaml.

Stop the pipeline if the data does not satisfy the contract.

Transform the validated data into Parquet format.

Partition the output by processing_date.

Upload the Parquet files to the MinIO bucket customers-lake.

Run the Project

Create your local .env file using .env.example as a template. Set appropriate local development credentials.

Start Docker Desktop.

Open CMD in this project folder.

Start the services:

docker compose up -d --build

Open the Airflow UI at http://localhost:8081.

Find and trigger the csv_to_parquet_minio DAG.

Open the MinIO Console at http://localhost:9001 and check the customers-lake bucket.

Validation

The DAG includes a schema validation step. Invalid data, including an invalid processing_date, should cause validation to fail before the data is loaded.

Generated Output

Parquet files are partitioned by processing date. They are generated by the pipeline and are excluded from Git.

Configuration Files

manifest.yaml — project manifest.

docker-compose.yaml — service configuration.

Security

Do not commit .env or real credentials. Keep .env.example limited to placeholders
